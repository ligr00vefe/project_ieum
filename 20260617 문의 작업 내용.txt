2. 관리자 문의 삭제 기능
----------------------------------------
- 관리자가 문의 상세 페이지에서 해당 문의를 삭제할 수 있는 버튼 추가
- 삭제 클릭 시 "정말 삭제하시겠습니까?" 확인 팝업 표시 후 삭제 처리

[추가된 코드 - detail.html]
<form th:action="@{/admin/inquiries/{id}/delete(id=${inquiry.id})}" method="post"
      onsubmit="return confirm('정말 삭제하시겠습니까?')">
    <button type="submit">문의 삭제</button>
</form>

[추가된 코드 - AdminInquiryController.java]
@PostMapping("/{id}/delete")
public String delete(@PathVariable Long id, RedirectAttributes ra) {
    inquiryService.delete(id, currentUserService.getCurrentUser());
    ra.addFlashAttribute("message", "문의가 삭제되었습니다.");
    return "redirect:/admin/inquiries";
}

[수정된 코드 - InquiryService.java]
public void delete(Long id, User user) {
    Inquiry inquiry = getById(id);
    boolean isAdmin = user.getRole() == UserRole.ADMIN;
    if (!isAdmin && !inquiry.getAuthor().getId().equals(user.getId())) {
        throw new ForbiddenException("본인의 문의만 삭제할 수 있습니다.");
    }
    inquiryRepository.delete(inquiry);
}


3. 문의 게시판 제목 검색
----------------------------------------
- 관리자 문의 목록, 일반 사용자 문의 목록 양쪽에 제목 검색창 추가
- 기존 카테고리/상태 필터와 검색을 동시에 사용 가능
- 검색어 지우는 초기화 버튼 제공
- 일반 사용자(장애인, 활동지원사)가 검색할 경우 비밀글은 결과에서 제외
- 관리자는 검색해도 비밀글까지 모두 확인 가능

[추가된 코드 - list.html (관리자/일반 공통)]
<form th:action="@{/inquiries}" method="get" class="flex items-center gap-2 mb-4">
    <input type="text" name="keyword" th:value="${keyword}" placeholder="제목으로 검색..."/>
    <button type="submit">검색</button>
    <a th:if="${keyword != null and !#strings.isEmpty(keyword)}"
       th:href="@{/inquiries}">초기화</a>
</form>

[추가된 코드 - InquiryRepository.java]
// 일반 사용자용 — 비밀글 제외
Page<Inquiry> findByIsSecretFalseAndTitleContainingIgnoreCaseOrderByCreatedAtDesc(String keyword, Pageable pageable);
Page<Inquiry> findByCategoryAndIsSecretFalseAndTitleContainingIgnoreCaseOrderByCreatedAtDesc(InquiryCategory category, String keyword, Pageable pageable);

// 관리자용 — 비밀글 포함
Page<Inquiry> findByTitleContainingIgnoreCaseOrderByCreatedAtDesc(String keyword, Pageable pageable);
Page<Inquiry> findByCategoryAndTitleContainingIgnoreCaseOrderByCreatedAtDesc(InquiryCategory category, String keyword, Pageable pageable);


4. 회원 관리 이메일 검색
----------------------------------------
- 관리자 회원 목록에서 이메일로 특정 회원을 빠르게 검색 가능
- 역할 필터(이용자 / 활동지원사 / 관리자)와 동시에 사용 가능

[추가된 코드 - UserRepository.java]
@Query("SELECT u FROM User u WHERE LOWER(u.email) LIKE LOWER(CONCAT('%', :keyword, '%')) ORDER BY u.createdAt DESC")
Page<User> findByEmailContainingAdmin(@Param("keyword") String keyword, Pageable pageable);

@Query("SELECT u FROM User u WHERE u.role = :role AND LOWER(u.email) LIKE LOWER(CONCAT('%', :keyword, '%')) ORDER BY u.createdAt DESC")
Page<User> findByRoleAndEmailContainingAdmin(@Param("role") UserRole role, @Param("keyword") String keyword, Pageable pageable);


5. 매칭 관리 제목 검색
----------------------------------------
- 관리자 매칭 목록에서 도움 요청 제목으로 검색 가능
- 상태 필터(모집중 / 매칭완료 / 진행중 / 완료 / 종료)와 동시에 사용 가능

[추가된 코드 - HelpRequestRepository.java]
@Query("SELECT r FROM HelpRequest r LEFT JOIN FETCH r.requester WHERE LOWER(r.title) LIKE LOWER(CONCAT('%', :keyword, '%')) ORDER BY r.createdAt DESC")
Page<HelpRequest> findByTitleContainingAdmin(@Param("keyword") String keyword, Pageable pageable);

@Query("SELECT r FROM HelpRequest r LEFT JOIN FETCH r.requester WHERE r.status = :status AND LOWER(r.title) LIKE LOWER(CONCAT('%', :keyword, '%')) ORDER BY r.createdAt DESC")
Page<HelpRequest> findByStatusAndTitleContainingAdmin(@Param("status") HelpRequestStatus status, @Param("keyword") String keyword, Pageable pageable);
